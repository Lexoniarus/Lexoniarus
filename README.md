# Hi, I'm Alex

I'm currently studying software engineering with a focus on AI engineering.

My background is not purely code-first. I come from business controlling, process optimization and IT-heavy workflows. That shapes how I look at software: I usually start with the process, the data and the real-world problem before thinking about the implementation.

This GitHub profile documents my current learning path.

The projects here are mostly exercises, experiments and MVP prototypes. They are not meant to look like polished commercial products. They show how I practice turning ideas into working systems, improving my coding skills, structuring projects and documenting scope, limits and decisions.

## Where I am strongest right now

My strongest angle is currently concept, process logic and system thinking.

I am good at looking at a workflow and asking:

- What problem is actually being solved?
- Where does human input enter the process?
- What data is involved?
- What needs to become more structured?
- What should be automated and what should stay under human control?
- How can an idea become a usable MVP?

Coding is the skill I am actively building to make these concepts practical and testable.

## Long-term direction

My long-term direction is AI-assisted workflow automation.

The idea is simple:

Human input is often valuable, but messy.

Reports, notes, reviews, calls, decisions and creative outputs can contain important context, but they are often hard to compare, search, reuse or process consistently.

I am interested in tools that help turn this kind of input into structured, consistent and usable data.

AI should support people, not replace them.

## Selected projects

### ComfyReview

A local FastAPI prototype for reviewing, curating and analyzing ComfyUI image outputs.

It supports ratings, filters, Arena-style comparisons, SQLite-backed stats and reusable generation context. The project is mainly a practical experiment around local AI workflow tooling and structured review processes.

### Tavernenbank

A playable Python and Arcade card game MVP.

It started as a learning project around game loops, UI structure, assets, tests and documentation. The project is now public as an archived playable prototype.

### Kompass der Krone

A private Python project focused on structured game systems, readable UI and long-term project planning.

It is mainly used to practice architecture, documentation, feature planning and iterative development.
